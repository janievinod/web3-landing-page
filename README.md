# 🪐 AURA OS 2035 | Sovereign Web3 Network Landing Page

An interactive, cyber-futuristic Web3 landing page experience built with modern HTML5, CSS3, JavaScript, and Canvas API. Demonstrates decentralization, sovereign digital identity, real-time Web3 wallet integration, and on-chain signature verification.

## 🌟 Key Features

* **Interactive Motion Background:** A dynamic Canvas 2D interactive particle lattice network that moves in real-time and reacts to cursor movements.
* **MetaMask Integration:** Seamless Web3 wallet authentication using `ethers.js` to detect account addresses, display connection status, and track account changes.
* **On-Chain Diagnostic Console:** Simulated & live node diagnostic panel that fetches live ETH balances directly from connected Ethereum wallets.
* **Cryptographic Signature Verification:** Gasless message signing functionality (`signer.signMessage`) verifying node ownership via MetaMask.
* **3D Interactive Knowledge Hub:** Modern CSS 3D perspective flip cards breaking down core Web3 architectural pillars.
* **Glassmorphism UI:** Built with glowing neon gradients, dark mode cyber aesthetics, responsive flexbox/grid layouts, and smooth navigation animations.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, 3D Transforms)
* **Scripting:** Modern JavaScript (ES6+), HTML5 Canvas 2D Engine
* **Web3 Library:** [Ethers.js v5.7.2](https://docs.ethers.org/v5/) (via CDN)
* **Icons & Fonts:** FontAwesome 6, Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*)
