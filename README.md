# 🪐 AURA OS 2035 | Sovereign Web3 Network Landing Page

An interactive, cyber-futuristic Web3 landing page experience built with modern HTML5, CSS3, JavaScript, and Canvas API. AURA OS 2035 introduces users to the future of decentralized technology through immersive visuals, real-time wallet connectivity, and interactive educational experiences covering blockchain, cryptocurrencies, smart contracts, NFTs, DAOs, and digital ownership.

## 🌟 Key Features

* **Interactive Motion Background:** Dynamic Canvas-powered particle lattice network with real-time mouse interaction.
* **MetaMask Integration:** Connect Web3 wallets using Ethers.js and view live wallet information.
* **On-Chain Diagnostic Console:** Displays connected wallet status and Ethereum balance information.
* **Cryptographic Signature Verification:** Verify wallet ownership through secure MetaMask message signing.
* **3D Interactive Knowledge Hub:** Animated flip cards explaining key Web3 concepts.
* **Glassmorphism UI:** Modern cyberpunk-inspired interface with neon gradients, blur effects, and responsive layouts.
* **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
* **Educational Web3 Experience:** Beginner-friendly explanations of blockchain technology and decentralized systems.

## 📚 Web3 Concepts Demonstrated

### 🔗 Blockchain

A decentralized and immutable ledger used to record transactions securely across a distributed network.

### 💰 Cryptocurrency

Digital assets that enable peer-to-peer transactions without relying on traditional financial institutions.

### 📜 Smart Contracts

Self-executing agreements that automatically perform actions when predefined conditions are met.

### 🖼️ NFTs (Non-Fungible Tokens)

Unique digital assets that can represent ownership of digital items, certificates, identities, and collectibles.

### 🏛️ DAOs (Decentralized Autonomous Organizations)

Organizations governed collectively by community members through transparent voting systems.

### 🌐 Decentralization

A model where control and decision-making are distributed across a network instead of being managed by a single authority.

### 🪪 Digital Ownership

Empowering users to truly own and control their digital assets, identity, and data.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, 3D Transforms)
* **Scripting:** JavaScript (ES6+), HTML5 Canvas API
* **Web3 Library:** Ethers.js v5.7.2
* **Wallet Integration:** MetaMask
* **Icons & Fonts:** Font Awesome 6, Google Fonts (Plus Jakarta Sans & Space Grotesk)
* **Deployment:** GitHub Pages
